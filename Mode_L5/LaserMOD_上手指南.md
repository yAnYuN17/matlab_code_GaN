## 2. 六个仿真步骤（核心流程）

这是 Berkeley 教程的骨架，也是整个软件的使用节奏：

| # | 步骤 | 做什么 |
|---|---|---|
| **1** | **建结构** | a) 画结构（用左侧层类型工具）<br>b) **划网格**（Global / Local Mesh 参数） |
| **2** | **设偏置** | `Bias Table` / `Bias Editor`，填 (I, V) 点，选稳态或瞬态 |
| **3** | **生成剖面** | 折射率 / 掺杂分布 |
| **4** | **算增益** | `Gain Calculation` → 得到 peak gain 曲线等 |
| **5** | **跑激光仿真** | `Simulate Laser`。若设了瞬态，还能出**频率响应**曲线 |
| **6** | **出图** | `Generate Plot`。**要出图前先核对 "Plot Data for Bias #"** |

## 4. 参数在哪改

| 参数 | 位置 |
|---|---|
| 电流、电压 (I, V) | `Bias Table` |
| **腔长 L、温度 T、内损耗 α_i、端面反射率 R** | `Global Settings` ⭐ |
| 符号变量（如 `Wridge`、`Xcenter`、`glob_temp`） | `Symbol Table` |
| 掺杂、三元/四元组分、厚度 w、宽度 d | **右键点画布上对应的层** |

⭐ **`Global Settings` 里有 L、T、α_i、R**——这正是我们讨论的「纵向闭合」需要的量，LaserMOD 内置了。

⭐ **符号变量是个大杀器**：截图里电极的宽度写的是 `Wridge`（不是数字），中心的 x 写的是 `Xcenter`。**改符号表一个数，整个结构跟着变**——阶段 3 要扫的"脊宽"就是它。

## 6. 坑（别人踩过的，共 10 条）

**Berkeley 教程明确点名的 8 条**：

1. 跟着**手册第 4 章**的教程走
2. AlGaAs 材料参数文件里，`kpmat_DIELOPT` 要设成 `Diel_Opt0`（影响折射率剖面）
3. **频率响应必须先成功做过瞬态脉冲响应**，且脉冲要回到稳态
4. **L-I-V 曲线的功率是"两个端面的总和"**，不是单面输出——报数时注意
5. 瞬态设置里：**第一个数 = 时间步长，第二个数 = 步数**；所有时间步必须相等
6. **变量区分大小写**（`Wridge` ≠ `wridge`）
7. **重跑前要清旧数据**：删掉 `.las` 同目录下生成的那两个文件夹，否则图上会叠着上次的曲线
8. **面载流子密度 (cm⁻²) = 体密度 (cm⁻³) × 总量子阱厚度 (cm)**

**另两条**：

9. ⚠ **手册与实际程序在 IV 特性上有出入**（材料文件更新了但手册没跟上）。若 L-I-V 看着不对，**在 1.4 V 到 25 mA 之间补偏置点**（例如补 1 mA 和 2 mA）
10. ⚠ **折射率可能是按"平方值"输入的**（例如 GaN：2.55² = 6.5025）——〔来源等级较低，是检索所得，**请你自己在界面上确认**，填错会全线出错〕

## 8. 有用的公式（Berkeley 第 14 页）——正好是你的「纵向闭合」

| 量 | 公式 |
|---|---|
| 输出功率 | P = (hν/q)·η_i·(α_m/(α_i+α_m))·(I − I_th) |
| **镜面损耗** | **α_m = (1/L)·ln(1/R)** |
| 阈值增益 | Γ·g_th = α_i + α_m |
| 阈值电流 | I_th = q·V·N_th /(η_i·τ_n)，V = L·w·d |
| 微分效率 | η_d = (hν/q)·η_i·(α_m/(α_i+α_m)) |

⚠ **一处必须注意的差异**：Berkeley 写的 α_m = (1/L)·ln(1/R)，这是**两端反射率相同**时的形式。验算一下：把 R₁ = R₂ = R 代入通式 α_m = (1/2L)·ln(1/(R₁R₂))，得 (1/2L)·2ln(1/R) = (1/L)·ln(1/R) ✓ 一致。

**但你的器件如果是 HR/AR 非对称腔（R₁ ≠ R₂），必须用通式 (1/2L)·ln(1/(R₁R₂))。** 这一点在路线文档里讨论过——非对称腔会让输出端面功率密度抬高约 2.3 倍（R₁=0.95/R₂=0.05 时），直接影响 COD 余量。

## 9. 一张重要的截图信息（电极属性对话框）

你截图里打开的那个对话框，是**电极元素**的属性。里面有两组：

**GEOMETRY INFORMATION**

| 字段 | 值 | 意义 |
|---|---|---|
| Element Width | `Wridge` | **符号变量**，扫脊宽就改它 |
| Element Height | `0.1` | |
| x Ref. (Center) | `Xcenter` | 符号变量 |
| y Ref. (Bottom) | `2.31` | 数字 |
| Reference To: Element # + Offset | | **相对定位**——这层挂在别的元素上，下层动上层跟着动 |

**MATERIAL INFORMATION** ⭐ **热参数在这里**

| 字段 | 值 |
|---|---|
| Workfunction (eV) | 5 |
| Electrode Type | `ohmic` |
| **Temperature (K)** | **`glob_temp`** |
| **Thermal Cond. (W/K·cm)** | **0.05** |
| **Heat Sink Thick. (μm)** | **1** |
| **Thermal Boundary** | **`dirichlet`** |
| Dispersion | `none` |

⭐ **温度、热导、热沉厚度、热边界四项全在，而且可设** → 之前悬着的"LaserMOD 能不能算热"，**基本可以放心**（但真正确认还要跑通一次）。

另外别忘了点开 **`Physical Data...`** 按钮，里面应该还有更细的材料参数。

## 10. 第一周的动手顺序（建议）

| 步骤 | 做什么 | 目的 |
|---|---|---|
| **1** | **原样打开并跑通 `fp2d`，一个参数都不改** | 确认环境正常、摸清菜单在哪 |
| **2** | 按 Berkeley 的 "Things to try" 改几个量，看 L-I 怎么变 | 建立因果直觉 |
| **3** | 打开 **`fp2d_ingan`**，看 InGaN 材料参数怎么填 | 为换到 GaN 做准备 |
| **4** | 改 `Global Settings` 的 L 和 R，看阈值与 η_d 怎么变 | **直接对应你的阶段 6** |
| **5** | 才开始换成自己的 GaN 层序 | — |

**Berkeley 教程给的四个练习**（照抄，都是低风险改动）：
- 降低腔长 L → 阈值上升、η_d 上升
- 改变量子阱数 → 阈值变化
- 改变条宽 w → 阈值变化，**但 η_d 不变**（这条最反直觉，值得做）
- 改变环境温度 → LIV 与波长变化
- 改变端面反射率 R → 阈值与 η_d 都变
