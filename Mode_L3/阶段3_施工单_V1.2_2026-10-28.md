## 0. 一句话任务

把阶段 2 的「垂直一维复模求解」扩成「垂直 + 横向」两步等效折射率法，解出**有限宽脊波导**的各阶侧模 n_eff、Γ、αᵢ，并用一个独立的二维求解器证明这套 EIM 没有算错。

**为什么现在做**：阶段 2 交的是无限宽平板（一维），得到 47 组数里最关键的三个——TE0 的 n_eff = 2.417133286、Γ = 0.026775、αᵢ = 6.1819 cm⁻¹。真实器件是几个微米宽的脊，横向一维自由度**完全没被算过**：侧模有几阶、脊宽 w 变窄时 Γ 掉多少、αᵢ 是涨还是落——这些都要到阶段 4（模式竞争）才用得上，但必须现在建对。

## 2. 本单唯一的新结构假设（**开工前先确认这三条**）

阶段 1/2 的层序把 p 包层写成 **Inf（半无限）**，这在数学上干净，但**无法表示脊**：脊必须有一个真实的顶面，让侧向刻蚀在两侧造出折射率台阶。所以本单引入三条新假设。它们**不是从阶段 2 继承的**，是新增的；真实外延/工艺参数一到，整体替换。

> ✅ **用户确认（2026-10-28）**：三条假设**按本单取值执行，不设备选、不再逐项讨论**——h_pclad = 0.30 μm、顶部介质 SiO₂（air 作对照）、h_e = 0.30 μm 为默认，敏感度扫描 {0.20,0.25,0.30,0.35} × w 照做。**本阶段只做准 TE，不交 TM 结果。**

| 编号 | 假设 | 默认值 | 依据 |
|---|---|---|---|
| **S1** | **p 包层有限化** | h_pclad = 0.30 μm，其上为顶部介质 | Inf 无法表示脊；0.30 μm 是 GaN 基蓝光 LD 常见 p-clad 厚度量级〔记忆，待企业参数核〕 |
| **S2** | **顶部介质** | 默认 SiO₂（n = 1.46）；并行算 air（n = 1.0）作对照 | 实际器件 p-clad 之上是 SiO₂ 绝缘 + p 电极；未钝化情形用 air 作上界 |
| **S3** | **刻蚀深度** h_e（从 p 包层顶面量起），脊宽 w | 默认 h_e = 0.30 μm（刻穿 p-clad，停在 p-wave 顶面），扫描 {0.20, 0.25, 0.30, 0.35}；w 扫描 {2, 3, 5, 10} μm + w = 50 μm 作极限 | 浅脊（刻到 EBL 之上）是蓝光 LD 的主流做法 |

**默认几何**（y 自 p-clad 顶面向下量，记作 y′）：

| 段 | y′ 范围 (μm) | 材料 | n @450 |
|---|---|---|---|

**脊/沟槽的定义**：脊区（0 < x < w）保留上表全层；沟槽区（x < 0 或 x > w）把 y′ ∈ [0, h_e) 的层替换成顶部介质（S2），y′ ≥ h_e 的层**不变**。只做**垂直侧壁**（前置 1），水平侧壁（刻蚀倾角）另议。

> ⚠ **h_e 与本表坐标必须自洽**：h_e = 0.30 恰好剥掉 p-clad；h_e = 0.35 会剥掉 0.05 μm 的 p-wave；h_e = 0.20 留下 0.10 μm p-clad。施工会话要打印每个 h_e 下沟槽区的层序（tag + 厚度 + n）并核对这一条，不许凭印象。

**本单只做准 TE（E ∥ x）**：脊波导的侧向限制靠有效折射率台阶，E ∥ 侧壁时边界条件连续、标量 EIM 成立；准 TM（E ∥ y）在垂直侧壁上场分量不连续，标量 EIM 不成立，且阶段 2 的 `solve_fdm` 在 TM 分支有已知缺陷（围栏 F1，未修）。**本阶段不交 TM 结果**，报告里要写一句「TM 留待阶段 4 之后另议」。

## 3. 任务（T1–T8）

**T1 结构扩展：有限 p-clad + 顶部介质**
在 `Main` 里新增 `stack_7l_ridge(lambda, h_pclad, n_top)`：p-clad 由 Inf 改 h_pclad，其上追加介质层 `n_top`（非半无限的存在方式按 `build_layers` 的半无限规则改造：新顶面之上再放一层 Inf 介质）。保留 `stack_7layer(lambda)` 原样不动（A0 回归要用）。两条路必须共存，不许「改掉旧的」。

**T2 EIM 第一步：两个区各自解垂直（y）向复本征**
- 脊区 y-slab：全层序 + SiO₂ 顶。
- 沟槽区 y-slab：按 h_e 剥层 + SiO₂ 顶。
- 每区解出的**基模** n_eff 记为 n_a（脊区）、n_b（沟槽区），两者都是**复数**，直接沿用阶段 2 的复根求解器（不许另写一套）。
- 输出并打印：`n_a, n_b, Re(n_a²−n_b²)`。**若 Re(n_b) > Re(n_a)（反导引），立刻停下报给用户**，不许自己加台阶凑数。

**T3 EIM 第二步：横向（x）一维复本征**
- 以 n_a 为芯、n_b 为包层，宽 w，解横向复本征问题，得总 n_eff（复数）与横向场 E_x(x)。
- **不得再注入任何吸收**：α 只能从 n_eff 的虚部来（前置 2）。第二步里出现任何 `one.ai` / `2*k0*imag(...)*1e4` 形式的二次赋值都是错的。
- 输出前 `m` 阶侧模的 n_eff、α = 2k₀·Im(n_eff)×1e4（cm⁻¹，k₀ 用 μm⁻¹，与阶段 2 同一口径）。

**T4 二维场重建、Γ 与层分解**
- E_y(x,y) = E_x(x) · E_y^slab(x, y)（在脊区用脊区 slab 解，沟槽区用沟槽区 slab 解）。
- **Γ 定义式必须写进报告**，并满足极限：w → ∞ 时退回阶段 2 的 0.026775。
  Γ_ridge = ∫|E_x(x)|²·Γ_y(x) dx / ∫|E_x(x)|² dx，其中 Γ_y(x) 是该 x 处 y-slab 的 Γ（脊区取 Γ_a，沟槽区取 Γ_b；两层 QW 都还在，h_e ≤ 0.35 不伤 QW）。
- 层功率 P_j 同理按 x 加权：P_j = ∫|E_x|²·P_j^y(x) dx / ∫|E_x|² dx。
- **不重写 Γ 口径、不重写 P_layer**：阶段 1 的分子分母定义照用，只是加了横向权重。

**T5 参数扫描**
- w ∈ {2, 3, 5, 10, 50} μm × h_e ∈ {0.20, 0.25, 0.30, 0.35} μm × 顶部 ∈ {SiO₂, air}。
- 每格给：各阶侧模个数、TE0 的 n_eff / Γ / αᵢ、侧模间的 Re(n_eff) 间隔、Γ·g−α 的相对排序（g 用占位值，只需排序稳定，见 T7 说明）。
- 三波长冒烟：450 / 405 / 520 各跑一次**只验证不报错**。⚠ 520 的 n 与 α 未取证（阶段 2 围栏 F5），**520 的数不得进任何结论**，报告里只能写「参数化通路通过」。

**T6 独立验算：二维标量有限差分解本征值**
- 自己写一个 2D 标量 FD 求解器（`sparse` + `eigs`，五点差分，复 n²），域：x ∈ [−3w, 4w]，y 覆盖到衬底，边界用 Dirichlet 拉远。
- **只比 Re(n_eff)**（虚部量级小、FD 误差大，不作判据）。
- 网格：dx = dy = 20 nm 跑一遍，再用 10 nm 复跑最窄的一档，检查网格收敛。
- 与 EIM 的差记 Δ = |Re(n_eff,EIM) − Re(n_eff,FD)|。

**T7 遗留缺陷 L3 的间隔检查**
- 打印**相邻侧模 Re(n_eff) 间隔的最小值** min_gap（全扫描里取最小）。
- 判据：min_gap > 100 × 1e-6 则继续豁免并记下该值；min_gap ≤ 100 × 1e-6 则**先改 merge 去重**（绝对容差 + 间隔自适应），改完再继续，不许带着已知会误合并的去重器往下跑。
- 报告里要写清「本次 min_gap = ___，出现在 w = ___，判据 ___」。

**T8 侧壁散射的参数化上界（不要求实测）**
- 公式（单侧壁，两个侧壁 ×2）：α_scat = 2·C·(4π²/λ⁴)·σ²·L_c·(n_GaN² − n_top²)²·η，η = |E_x(侧壁)|² / max|E_x|²，C 取 1（真系数 O(1)，写成"上界"）。
- 网格：σ ∈ {0.5, 1, 2} nm × L_c ∈ {10, 30, 100} nm，每个 w 一格。
- 输出 α_scat 表 + α_scat/αᵢ 比值；**不要求**拟合、不要求与文献对齐、不要求实测 σ。
- 预期量级（我按 η = cos²u、u tan u = (w/2)k₀√(Δn_eff²) 粗估，σ = 1 nm、L_c = 30 nm）：w = 10 → ~0.1；w = 5 → ~0.3；w = 3 → ~0.6；w = 2 → ~1.1 cm⁻¹；σ = 2 nm 时全部 ×4。**落到 0.03–6 cm⁻¹ 这个区间都算合理**，超出 10 倍要回头查 η 或 Δn²。

**T9 远场与图件（用户 2026-10-28 追加）**

## 5. 把手（用户 30 秒内能自查）

1. **极限**：A1 的 w = 50 μm 就是在验「脊无限宽时退回阶段 2 的平板」。看日志里 `n_a` 与 `n_eff(w=50)` 两个数，差值应当在小数点后第 5 位之后。
2. **不等式**：任意一格里必须同时成立 `Re n_b < Re n_eff < Re n_a`，且 `Γ_ridge < Γ_slab`、`αᵢ(脊) ≤ αᵢ(平板)`（沟槽剥掉了 p 侧吸收层，只会更小；若反而变大，说明场被推到沟槽里了，要查）。
3. **散射算式**（自己按计算器）：α_scat[cm⁻¹] = 2 × 39.478 × σ²·L_c × (n_GaN²−n_top²)² / λ⁴ × η × 1e4 —— σ、L_c、λ 用 μm。σ=1nm、L_c=30nm、Δn²=3.895、η=0.07 代回得 ~0.6（w=3）。表里若出现 6 cm⁻¹ 而 η 只有 0.07，就是算错了。
4. **量纲**：`2k₀·Im(n_eff)×1e4` 里 k₀ 用 μm⁻¹（=13.96 @450 nm），乘 1e4 才是 cm⁻¹。阶段 2 的 B4 就是靠这一步对上 10.0 的。
5. **慢轴 FWHM 与脊宽**（远场图自查）：高斯近似 θ_FWHM ≈ 0.886·λ/(n_eff·w₀)，w₀ 取横向 1/e² 半径。w = 3 μm → w₀ ≈ 1.5 μm、n_eff ≈ 2.4 → 0.886×0.45/(2.4×1.5) = 0.111 rad ≈ **6.4°**。图上慢轴 FWHM 落在 4°–9° 算方向对；若出现 ~1° 或 ~30°，是 sinθ 换算或 k₀ 单位错了。
6. **瓣数与模数**：等幅同相叠加，参与叠加的模越多，主瓣两侧的瓣越多；把 c 设成 [1,0,…] 时必须退回单峰（对照用户图 3 的两个凹陷）。**瓣数对不上模数，就是 F_k 的符号错了**——符号必须来自同一个二维变换，不许按 |F_k| 叠。
