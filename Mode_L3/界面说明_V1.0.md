界面**回到 uifigure 版**（你判定画质与手感更好），成果图的绘图函数用当天改过的版本。与上一版相比只动四处：

4. **按钮文字「高级设置…」**：齿轮字符在你的字体里会显示成方框。

成果图（第 1、5、11 项）也一起改了：竖直剖面改**双纵轴**（左轴 |Φ|²、右轴 n(y) 真值，不再把 n 压到 0–1 里），

## 2. 三列各管什么

**① 波导结构**

- 波导类型：脊形 / 矩形。切到矩形后，脊宽、脊高两栏自动隐藏（矩形没有侧向台阶）。
- 层表（自上而下显示：顶层 … 衬底）：点一行 = 选中这一层；行尾 `✕` 删除。
  - 衬底（第 1 层）与顶层不可删，层数 ≤ 3 时删除键全部置灰。
  - `＋ 添加一层` 插在**顶层下方**（即结构靠近表面的地方），tag 自动叫 `layerN`。
- 慢轴长 / 快轴长 / 纵轴长（默认 10 / 2.5 / 1500 μm）、脊宽（3 μm）、脊高（0.30 μm）。

**② 层参数**（改的是①里选中的那一层）

- tag、折射率 n、损耗 α [cm⁻¹]、厚度 d [μm]、是否有源层（QW，最多一层）。
- 损耗走**折射率正虚部**：界面里填的 α 会换算成 `Im n = α/(2k₀·10⁴)`，
  与主模型 `n_of_lambda` 里的式子完全一致，所以不会出现"两套损耗"。
- 左上角 **高级设置**：波长、顶部介质折射率（1.46 = SiO₂）、根扫描点数、收敛容差、
  去重门限、模场网格点数、尾部衰减长度、远场采样数。

**③ 三维示意**：每层一个颜色，竖轴按比例压缩，衬底按 10% 高度示意。
- **初始正对 x–y 截面**（慢轴横、快轴竖），层序与脊宽一眼可见；拖动可旋转成斜视图。
- 面板下方 **－ / 百分比 / ＋ / 复位**：缩放改的是坐标范围、相机始终在盒外，
  所以不会像滚轮那样"钻进结构内部"；复位回到 100% 且正对截面。

## 3. 校验（输入一变就查，不弹窗）

非法时底部按钮 **Sure 置灰**，第一列下方红字写原因。查的项：

轴长有限正；层数 ≥ 3；首层厚度必须 ∞；顶层厚度有限正；中间层 d > 0 且 n ∈ [1, 5]；
α ≥ 0；中间层厚度和 ≤ 快轴长；总厚 ≥ 5% 快轴长（否则三维图看不清）；tag 不重复；
有源层 ≤ 1；**脊宽 ∈ (0, 慢轴长]**；**脊高 ≤ 顶层厚度**（本阶段不允许刻穿，按你 2026-10-28 的拍板）；
脊高 ≤ 快轴长；顶部介质 n ∈ [1, 4]；λ ∈ [0.2, 1.5] μm。

## 4. Sure 之后：成果画布

点 Sure → 先用**当前结构**算一遍（竖直 → 横向 → 二维场 → 远场，约 1 s）；
若这一步不可解（例如把某层折射率改小导致反导引），画布直接写「无法求解」+ 原因，**不拿旧数冒充**。

左侧 11 个按钮，**一项一行**（说明挂在鼠标悬停提示上，选中后也显示在画布下方），一次出一张，全部是现算的：

| # | 按钮 | 内容 |
|---|---|---|
| 1 | 竖直结构剖面与模场 | n(y) 台阶 + \|Φ\|²，QW 用洋红标出 |
| 2 | 竖直模场快轴远场 | 竖直各阶的 1D 远场与 FWHM |
| 3 | 竖直各阶数据表 | 脊形侧模的 Re/Im n_eff、Γ、αᵢ 与层加权对照 |
| 4 | 横向模场 E_x(x) | 各阶侧模的强度，虚线是脊边 ±w/2 |
| 5 | 二维模场 \|E(x,y)\|² | E_x(x)·Φ(x,y)，洋红线是 QW 上下沿 |
| 6 | n_eff / Γ / α vs 脊宽 | 当前脊宽的 0.5–2 倍扫 5 个点 |
| 7 | 二维远场 θx–θy | 强度 dB，**黑线**是 0.5 与 0.135 等高线 |
| 8 | 快轴远场（2D 场） | 各阶单画 + 等幅同相叠加（黑虚线） |
| 9 | 慢轴远场（2D 场） | 同上，慢轴 |
| 10 | EIM 与二维有限差分对比 | 当前结构 Re N：两步 EIM vs 五点差分（约 20 s） |
| 11 | 损耗分解 | 逐层 P_j·α_j·n_rj/Re N 的贡献 |

画布是**白底**；每张图开始前都会把坐标轴复位（线性/正常方向/自动范围/清图例），
所以上一张的 `axis tight` 或对数轴不会串到下一张。

**矩形波导**下，与侧向限制有关的那几张（4–10）会直接写「矩形波导没有侧向限制，这一张不适用」，
不画假图；1、2、3、11 照常出。

```

Im N   = 2.111e-05    2.046e-05    1.884e-05
Γ      = 0.026712     0.026154     0.024779
αᵢ     = 5.8936       5.7129       5.2618  cm⁻¹
EIM vs 2D FD：2.4161455 vs 2.4160773，|Δ| = 6.8e-05
```

## 6. 已知限制

- **没有侧壁角参数**（你 2026-10-28 说暂时不用）：三处硬编码垂直墙（`e3_stack_pair` 的两套层表、
  `e3_lateral_solve` 的矩形芯、`e3_fd2d` 的 `|x| > w/2` 判据）。要加会牵动整条 EIM 链，不是加个输入框的事。
- **脊高不能超过顶层厚度**（不许刻穿），超过时校验直接报错。
- 纵轴长目前只影响三维示意与界面参数，不参与本阶段的二维横截面计算（阶段 3 不做腔面与 z 向传播）。
- 只做准 TE。偏振下拉框固定为 TE。
