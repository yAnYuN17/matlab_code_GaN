## 3 S3 复折射率通路（PASS）

做的事：层折射率变复数 `n = n_r + i·α/(2k₀·1e4)`，并补两处保护。

1. `alpha_of_layer` 读全局表 `STAGE2_ALPHA`（`containers.Map`）。**必须用 Map**：层名带 `-`（`n-clad`），`s.(tag)` 动态字段会报"字段名无效"。
2. `dispersion_tmm` 里 `gam_sub`/`gam_cov` 加 `stage2_decay_branch` 分支保护——原注释写着"必须取衰减解，Re γ>0"，但**代码从未执行该判据**；复参数下 `sqrt` 会自动选主值分支，可能选成增长解。
3. `src\build_layers.m:60` 的 `imag(n) >= 0` 断言**未改松**（施工单 F2），复折射率通路能正常通过它。

冒烟（δ = 全层同值虚部）：

| δ | Im(n_eff) TE0 / TE1 / TE2 |
| --- | --- |
| 1e-6 | 1.005593e-06 / 1.003747e-06 / 1.010578e-06 |
| 1e-5 | 1.005593e-05 / 1.003747e-05 / 1.010578e-05 |
| 1e-4 | 1.005593e-04 / 1.003747e-04 / 1.010578e-04 |

Re(n_eff) 到 1e-12 不变；ΣP_layer − 1 ≤ 2.2e-16；Γ 不变。

### ★ 由这一步得到的核心物理结论（一手，数值已验证）

全层同 α 时 **Im(n_eff) ≠ δ**，而是

```
Im(n_eff) = δ · Σ_j P_j·n_rj / Re(n_eff)
```

一阶微扰 δ(n_eff²) = ∫δ(n²)|E|² / ∫|E|²，而 δ(n²) = 2n_r·iδ ⇒ δn_eff = iδ⟨n_r⟩/n_eff。
验算：TE0 的 ⟨n_r⟩ = 2.4305，2.4305/2.417128 = 1.00554，实测 1.005593（差 5e-5 是二阶项，不是求解器误差）。

**后果**：`α_mode = Σ_j P_j α_j` 只是近似；严格式见下节。这条结论直接决定了 B1 判据该跟谁比。

实分支与复分支都接了；排序同时从"按模"改成"按实部降序"（否则模序会乱，A1 同类问题）。

### 踩过的坑（已写进坑记录素材）

- 最初用 `(x−2.40)² + i·1e-11` 造伪根，**结果被接受**——全纯函数加复常数在复平面照样有零点，那不是伪根，是构造错了。必须用**非全纯**（含 `abs`）的表达式才造得出"|f| 在某个方向降不下去"。
- `chk = []` 后 `chk(end+1) = struct(...)` 报"无法从 struct 转换为 double"（D1 同类）；后来加字段 `c.rmax` 又报"在不同结构体之间进行字段名赋值"——**struct 数组的字段集合必须一次定死**，空模板 `stage2_empty_check` 里也要有。

## 6 S6 TMM 数值稳定性（判定：选 (a)，不需要散射矩阵）

做的事：三层均匀吸收构型（n_core 2.455 / n_clad 2.404），把 α 从 1 cm⁻¹ 扫到 1e5 cm⁻¹，用**独立的三层解析色散**做参考（不拿 TMM 的根当种子），测 TMM 的复根与解析根之差。

### 决策点一：解析参考用什么形式

- **tan 形式（已采用）**：`cap·tan(cap·d/2) − γ = 0`，`γ` 用与 TMM 同一分支约定 `stage2_decay_branch`。
  - 依据：复参数下 `atan` 取主值会跳分支，`tan` 形式没有多值问题。
  - 代价：方程有极点（`cap·d/2 = π/2`），牛顿要避开，故用窄窗口 + 连续化 seed。
- **atan 形式（初版，已弃用）**：`cap·d = mπ + 2·atan(γ/cap)`。代价：α 大时 `atan` 分支跳变，解析根自己就错，参考解不可信。
- **fdm 做参考（未采用）**：代价：TM 分支本身有缺陷（坑记录 A6/L1），且 Dirichlet 边界会造假日模。

### 决策点二：判定 (a) 还是 (b)

| 段 | 构型 | 结果 |
| --- | --- | --- |
| 一 | d=0.12，全窗口 [2.404, 2.455] | α ≤ 1e4：dn = 0、dα/α ≤ 2.0e-16；α ≥ 3e4：找不到根（found=0） |
| 二 | d=0.30，窄窗口 ±0.02 | α = 100…3000：dn = 0，cond(M) 恒 2.54e1；α ≥ 1e4：找不到根（此时 \|Im κd\| 仅 6.5e-3） |
| 三 | d=5.0，多模（反面对照） | TMM 选错根：α=100 时 dn = 2.81e-2（全）/ 1.64e-2（窄） |
| 四 | **真实 7 层 + 量级 α** | n-clad 36 / p-clad 18 / EBL 36 cm⁻¹ ⇒ Re(n) 变 5.119e-5、Γ 变 3.648e-8、Im(n)=5.1192e-5、**α_mode = 14.2956 cm⁻¹**、cond(M)=2.4676e4、根后验 max ratio = 1.19e-6 |

判定 **(a)**：目标量级（α ≤ 100 cm⁻¹）内 TMM 误差 1.51e-16 ≪ 1e-6 ⇒ **不换散射矩阵**，S6 结案。

"失真起点"如实记为 **onset = Inf（在可解域内未观察到精度失真）**；先失效的不是精度而是**求根**：\|Im κd\| 超过约 5e-3（α ≳ 1e4）后，实轴扫描漏掉极窄的零，表现为"找不到根"或"给出非零局部极小"。

### 第三段暴露的真问题与修法

d=5、α=100 时解析根 2.454631262074（|f| = 1.2e-11），TMM 返回 2.453525312，那里 **|f| = 33.4**——不是根，是 |f| 的一个陡峭深坑。原后验检查只比 ratio（fr/nb），深坑也能通过。

修法：加**绝对残差门限** `fr ≤ chk_res·max|f|`（`chk_res = 1e-6`）。S4 复跑仍 pass=1，真实三根不受影响。

**已知局限**：d=5 那种构型若 `max|f|` 极大（指数增长），相对门限会被放大而失效；该构型不是本项目结构，记入坑记录，S7 的真实结构不受影响。

**把手**：`run test_stage2\test_s6_tmm_stability.m`，末行 `S6 TEST onset=Inf  max_rel(alpha<=100)=1.514e-16`。

### 做了什么
