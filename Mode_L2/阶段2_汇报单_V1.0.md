## 2 这一阶段取到了什么

1. **450 nm TE0 的内损耗 α_i = 6.18 cm⁻¹**（Kioupakis 2010 参数化，全层赋 α）；
   若按施工单的最小假设（只有 EBL 36 + p 包层 18），α_i = 2.46 cm⁻¹。
2. **通道分解（450 nm，KIO）**：n 侧 0.8779 / 有源区 0.6788 / p 侧 4.6103 cm⁻¹，
   p 侧占 74.6%——施工单预判的"p 侧主导"成立。
3. **严格微扰式**：α_mode = Σ_j P_j α_j·n_rj / Re(n_eff)，不是 Σ_j P_j α_j。
   字面式的偏差恰等于 |n_rj/n_eff − 1|（衬底 27%、QW 5.5%、其余 0.5–3%）。
4. **厚度扫描**：α_i 在 t≈0.10–0.12 μm 附近有极大（6.66 cm⁻¹），此后随 t 缓慢下降
   （0.30 μm 时 6.07）；Γ 的峰在 t=0.12（0.028864）。**"加厚降损耗"只在 t>0.12 成立。**
5. **衬底扫描**：n_sub 从 1.70 扫到 2.44，束缚模在 n_sub ≤ 2.416 一直存在
   （Re(n_eff)=2.417133），n_sub ≥ 2.418 起本实现的搜索窗口内无根。
6. **TMM 数值稳定性**：在本项目关心的 α ≤ 40 cm⁻¹ 范围内 TMM 与三层解析解逐位一致
   （|Δα|/α ≤ 2.0e-16）。失效不是矩阵病态，而是 α ≳ 3e4 cm⁻¹ 时复根离开实轴
   （Im n_eff ≈ 0.1），实轴扫描找不到它。

### B1 弱吸收极限（★总闸门）——**PASS（按口径 A）**

- 21 个算例（7 层 × α ∈ {1,3,10} cm⁻¹），逐层单独赋吸收。
- 判据（用户 10-20 拍定口径 A）：与 `P_j·n_rj/Re(n_eff)` 比，相对偏差 < 1e-2。
- 实测最大偏差：**1.87e-4**（substrate 与 p-clad 各一次），其余层 ≤ 2.2e-5。
- 字面式（与 P_j 比）的最大偏差 2.68e-1（substrate），逐层值见下表；
  偏差恰等于 |n_rj/n_eff − 1|，是物理（严格式少了一个 n_r 权重），不是求解器误差。

### B5 "加厚降 α_i 但 Γ 也降"——**PASS（有交叉结构）**

- α_i(t)：4.134 → 峰值 6.6607（t=0.10）→ 6.0740（t=0.30）；**非单调**。
- Γ(t)：0.012657 → 峰值 0.028864（t=0.12）→ 0.021579（t=0.30）。
- 方向判定：Γ·g − α_i 在 g = 500 / 1000 cm⁻¹ 下对所有 t 都为正（最大 7.78 / 22.21，t=0.12），
  即 t=0.12 一带同时是 Γ 峰与净增益峰；**没有出现净增益变负的交叉厚度**。
- 注意：g 是假设值，阶段 4 拿到真实增益后要重算这张表。

### B6 泄漏通道识别——**PASS（部分，泄漏模求解留阶段 3）**

- n_sub 从 1.70 扫到 2.44（粗 0.05、细 0.002）：n_sub ≤ 2.416 全是束缚根，
  Re(n_eff) 从 2.417128409 单调升到 2.417133286；n_sub ≥ 2.418 起窗口内无根。
- 阈值判据：束缚要求 Re(n_eff) > n_sub；末一个满足的 n_sub = **2.416**，
  下一个点 2.418 已超过 Re(n_eff) = 2.41713。
- **必须说清的边界**：这里的"无根"是束缚模求解器窗口下界 n_lo = max(n_sub, n_clad) 造成的，
  不是"模消失了"。真正的泄漏模要在复平面找（PML/开放边界），归阶段 3。
- 结论：本结构对衬底折射率不敏感（n_sub 从 1.77 升到 2.40，Re(n_eff) 只变 1.6e-6），
  因为衬底场占比只有 1e-4；GaN 衬底与包层折射率接近是弱泄漏，不是零泄漏。

### B7 单位换算独立验证——**PASS**

- α[cm⁻¹] = 2k₀·Im(n_eff)·1e4，k₀ = 2π/λ [μm⁻¹]。450 nm：α = 10 ↔ Im(n) = 3.581e-5；
  405 nm：3.223e-5；520 nm：4.138e-5。
- 独立自检：S3 冒烟里全层同赋 δ = 1e-6，实测 Im(n_eff) = 1.005593e-6，

### B9 TMM 稳定性结论有证据——**PASS，判定 (a)：不需要 S 矩阵**

- 构型：对称三层 n_core 2.455 / n_clad 2.404 / d = 0.12 μm，三层同 α，α 从 0 扫到 1e5。
- 参考解：三层解析色散（tan 形式，复数牛顿，seed 独立，不拿 TMM 根当种子）。
- 实测：α ≤ 1e4（α·d ≤ 0.12）时 |Δα|/α ≤ **2.0e-16**，其中 7/10 个点两根逐位相同（差 0）。
- 失效点：α ≥ 3e4 起窗口内无根。根因**不是矩阵病态**，是复根离实轴太远：
  α = 3e4 cm⁻¹ ⇒ Im(n_eff) ≈ 0.1，实轴扫描的 |f| 极小值定位失效。
- 本项目 α ≤ 40 cm⁻¹（α·d ≤ 0.005），比失真点低 4 个量级 ⇒ **结论 (a)：TMM 够用，不实施 S 矩阵**。
- 补充证据（第二段，d = 0.3 μm，窄窗口 ±0.02）：
  α = 100 / 3000 时 TMM 根与解析根**复数逐位相同**（实部、虚部全同），α = 1000 时末位差 1e-15；
  α ≥ 1e4 时 TMM 返回空，而解析解仍然存在（Im n_eff = 0.036 @1e4、0.108 @3e4）。
  所以限制在**求根**（实轴初扫 + 收敛域），不在矩阵精度；失败点还依赖 d 与窗口
  （第一段同样 α=1e4 就能求出根）。
