## 1. 建模约定

> 这些是**前序会话讨论确定**的，后续所有阶段都必须一致，否则要返工。

### 1.1 七条硬约定

| # | 约定 | 要点 |
|---|---|---|
| 1 | **Δn(N) 走参数化路线** | 用 Δn = −(λ/4π)·α_H·Δg。**不做**"带填充 + 带隙收缩 + Drude"的分项相加 —— 那是重复计数。⚠ α_H 现有值 2.1–6.3 出自 2003–2004 年，**缺 450–500 nm、多 QW、实际工作电流下的值** |
| 2 | **"自聚焦"只保留两种** | 载流子饱和型（阶段 4）、热致型（阶段 5） |
| 3 | **"泄漏"是两个不同的量，不要混** | 光学泄漏（衬底/包层漏模）→ 阶段 2 进 α_i；载流子泄漏（电子溢过 EBL）→ 阶段 5 进速率方程，前四阶段完全没有 |
| 4 | **腔面损耗 α_m 归阶段 6** | 阶段 1–5 一律不出现（它们是截面问题，z 方向只以 exp(−iβz) 出现）。建议阶段 6 开头显式加一步"纵向闭合"：由 L、R₁、R₂ 算 α_m → 阈值条件 → J_th → η_d → 端面功率密度 → COD 余量 |
| 5 | **阶段 4/5 的 η_d 要声明为近似** | 显式写成"**无纵向修正的近似**"，纵向修正留到阶段 6 |
| 6 | **走稳态解 = 放弃横-纵模竞争** | 那是 60–80 MHz 的动力学现象，需在开题中声明这条边界 |
| 7 | **BPP 报告必须写清口径** | 二阶矩（ISO 11146）还是 86% 功率圈；相干还是非相干叠加。同一模块按不同口径算，**亮度可差 2–3 倍** —— 写清口径本身就是中文核心/EI 的加分项 |

### 1.2 判据纪律

> **任何一条验收判据若达不到，不许自行放宽阈值、不许换用更松的判据、不许把该条改为"已知限制"后跳过。**

正确做法：**填实测值 + 原判据要求的判据值 + 差异量级，报告回来。**

这条的来由是本项目亲历的一次教训：核查脚本第一版用"fdm 网格收敛比应 ≈ 4"当判据，实测 2.72，**误判为 FAIL**。
根因是**判据本身设计错了**（比较了不嵌套的网格），不是求解器有问题。
**放宽判据和误判判据都是错，只有报告回来才能分清是哪一种。**

配套：判据用**绝对/相对偏差**，**不得**用"收敛比 ≈ 4"（理由见《开发坑记录》B3）。

## 2. 模型说明

### 2.1 模型是什么

一个**非对称多层平板波导的 TE/TM 本征模求解器**。给定一摞折射率不同的薄层，解出：

- 各阶模的**有效折射率 n_eff**（本征值，阶段 1 为实数）
- 各阶模的**模场剖面 φ(y)**
- 各阶模的**限制因子 Γ** 与**各层功率占比**
- 各阶模的**快轴远场角分布**与 **FWHM 发散角**

### 2.2 求解路径的选择

| 路径 | 方法 | 层数限制 | 角色 |
|---|---|---|---|
| `analytic3` | 三层解析超越方程 κd = arctan(γ_s/κ) + arctan(γ_c/κ) + mπ | **仅严格三层** | 标尺 |
| `tmm` | 2×2 传输矩阵连乘，求色散函数零点 | 任意 | **生产路径** |
| `fdm` | Helmholtz 方程离散成稀疏矩阵本征值问题，`eigs` | 任意 | 标尺 |

**为什么生产路径给 tmm 不给 fdm**：fdm 的 Dirichlet 边界会把辐射模离散成假模，靠判据"n_eff 必须大于两侧包层折射率"剔除，
**接近截止的高阶模可能被误剔**。

**为什么必须有第三条路径**：路径 1 与路径 2 虽然数学路径不同，但**共享同一套"分层 + 界面连续 → 色散方程"的推导**。
若推导本身写错（例如 TM 的界面条件写成 TE 的），两条会**一起错**，A1/A2 双双通过而结论是错的。
所以另加了两条独立防线：`t00` 用符号运算**从 Maxwell 方程重推**（差 = 0），`fdm` **连色散方程这个中间产物都不要**。

⚠ **已知缺陷**：`fdm` 的 **TM 分支是失效的**（函数签名收 `pol`，函数体内从不使用）——
`solver='fdm'` + `pol='TM'` 会**静默返回 TE 结果**。详见 §3.2 与《开发坑记录》A6。

### 2.4 层结构

**7 层（默认）**：衬底 / n包层 / n波导 / QW / p侧无掺杂波导 / EBL / p包层

| # | tag | 材料 | d (μm) | n @450nm | 角色 |
|---|---|---|---|---|---|
| 1 | `substrate` | Al₂O₃ | **Inf** | 1.770 | 衬底，半无限 |
| 2 | `n-clad` | n-Al₀.₀₆GaN | 1.200 | 2.404 | n 侧包层 |
| 3 | `n-wave` | n-In₀.₀₄GaN | 0.120 | 2.455 | n 侧波导层 |
| 4 | `QW` | In₀.₁₅GaN | 0.009 | 2.550 | **有源区** |
| 5 | `p-wave` | u-In₀.₀₄GaN | 0.080 | 2.455 | p 侧无掺杂波导层 |
| 6 | `EBL` | p-Al₀.₂₀GaN | 0.020 | 2.343 | 电子阻挡层 |
| 7 | `p-clad` | p-Al₀.₁₀GaN | **Inf** | 2.374 | p 侧包层，半无限 |

**9 层（`'9'` 参数）**：把单层等效的 QW（9 nm）换成 **阱-垒-阱**（3/6/3 nm），其余不变。

**三条必须留意的**：

1. **首尾两层厚度必须是 `Inf`**。截断最外层等于凭空插进两个界面，会解出物理上不存在的假模，`build_layers` 对这条**直接报错**。
2. **层序从下往上**，`L(1)` 在衬底侧，`L(end)` 在覆盖层侧。这个方向贯穿模场、Γ 积分与绘图，中途不能反转。
3. **折射率不是单调的**。EBL 的 2.343 比上下两层（2.455、2.374）都低，是全结构唯一的"反向"台阶。
   它在光学上的作用是**把光往 n 侧推**（TE0 有 68.0% 在 n 侧、29.3% 在 p 侧）；
   但这是**附带作用**，EBL 的主要职责是**阻挡电子** —— 这句话要写进论文。

> **折射率数值的可信度**：锚在 GaN ≈ 2.43 @450 nm 及"GaN 与 Al₀.₀₆GaN 的折射率差 ≈ 0.026"上，
> 按 Al 组分线性外推（斜率 ≈ 0.433/单位组分）。属**量级可靠、末位不可靠**。
> 真实外延结构应尽早向企业索取后整体替换。

### 2.5 Γ 的口径

```
Γ ≡ ∫_{有源区} w(y) dy / ∫_{-∞}^{+∞} w(y) dy
    TE : w = |E_y|²          TM : w = |H_y|²/n²
```

**两处都必须钉死**（这正是文献里 Γ 不可比的根源）：

1. **分子范围**：单阱 / 全部阱层并集 / MQW 区（含势垒）—— 三者能差 2–3 倍。
   本项目取 **全部 `is_active` 层的并集（不含势垒）**。
2. **分母范围**：无穷积分 vs 截断到外延结构。**对漏模只有无穷积分自洽**。本项目取无穷积分。

配套口径：`Γ(全部阱) × g(单阱材料增益)`。若某处改用"MQW 区平均材料增益"，必须**另算一个 Γ_MQW**（分子含势垒），**两者不可混用** —— 混用会让模式增益偏离 2 倍以上。

### 2.6 符号与单位约定

**唯一定义处**：`DS_Deve/startup.m` 的头注释（同义写在 `Mode_L1_V1.0/README.md` §1.3）。

| 量 | 单位 |
|---|---|
| 长度（层厚 d、波长 λ、坐标 y） | **μm** |
| 折射率 | 无量纲，n = n′ + i·n″ |
| 真空波数 | k₀ = 2π/λ [μm⁻¹] |
| 传播常数 | β = k₀·n_eff [μm⁻¹]，转 cm⁻¹ **乘 10⁴** |
| 吸收系数 | α [cm⁻¹] = 2·k₀·Im(n_eff)·**10⁴** |

时间因子取 exp(−iωt)，沿 +z 传播取 exp(+iβz)，于是 α = 2·Im(β)：

> **Im(n_eff) > 0 表示损耗，Im(n_eff) < 0 表示净增益。**

阶段 1 全部取 Im(n_eff) = 0，这条约定现在不生效 —— 它的价值在阶段 2 兑现：
**如果符号反了，"增益算成损耗"会让所有数值检查照样通过。**

### 2.7 本模型不管的方向（已排除的路线）

以下路线**已经过论证排除**，不要再走一遍：

| 已排除 | 理由 |
|---|---|
| **Kerr 自聚焦** | 量级差 1000 倍（P_cr ≈ 1.2 kW vs 腔内 ~30–100 W；折射率增量也差 1000 倍） |
| **λ/2 驻波空间烧孔** | 载流子扩散长度 L_d ≈ 0.5–2 μm **≫** λ/2n ≈ 92 nm，被扩散抹平 |
| **Δn 分项相加**（带填充 + 带隙收缩 + Drude） | **重复计数**——三项已被吸收进 α_H 一个数里，再单列 Drude 项是常见错误 |
| **以 Lumerical MODE/FDE 为阶段 3 的主力工具** | ⚠ 在 GaN 边发射 LD 模式设计上**几乎没有可引用先例**，方法论需自证。COMSOL 与自编求解器风险最低 |
| **ARROW / 反谐振阵列、HCG 迁移、纳米多孔流片、自编时域成丝模型** | 见《GaN_LD_研究方向与文献清单》§6，各有明确排除理由 |

**另外一条方向性的**：

> **纵向（z）驻波在本课题里是死通道。** 纵向驻波周期 λ/2n ≈ 92 nm，被载流子扩散（L_d ≈ 0.5–2 μm）抹平。
> **阶段 1 的腔长 L 根本不出现在方程里** —— 这里的驻波是**横向（y）**的，即横向往返相位条件
> 2κd − 2φ₁ − 2φ₂ = 2πm，每满足一次多一个模式。
> **这条必须背下来**：导师提的"模式竞争"分歧正落在这里 —— 纵模/模簇竞争 vs 侧向模竞争，验收量完全不同。

### 2.8 远场口径（快轴）

**定义**：远场角分布 = 近场的空间傅里叶变换（Fraunhofer 近似）

```
Φ(θ) ∝ ∫ φ(y)·exp(−i·k₀·sinθ·y) dy      θ 相对 z 轴，范围 ±π/2
```

发散角取 **FWHM**（自峰值向两侧各找第一个降到半高的点，两点夹角）。

**三条必须一起报的口径**：

1. **θ = 0 不对应任何 y。** 角度是近场的**空间频率**而非位置 —— θ = 0 即所有 y 同相叠加
   （Φ(0) = ∫φ(y)dy）。所以 0° 处的高低反映近场正负相消的程度：TE0 单峰 → 1.00；
   TE1 / TE2 多瓣 → 0.73 / 0.28。远场 |Φ|² 与 y 的原点选取无关。
2. **多瓣模的 FWHM 必须连 `th_pk` 一起读。** 判据路过中央凹陷时：凹陷比半高亮 → 横跨
   两瓣（TE1：34.83° 是**包络宽**）；凹陷比半昏暗 → 只量到峰值那一瓣（TE2：15.70°
   **不是**发散角）。**同一个数字，两种含义** —— 报告时成对给出 `fwhm` 与 `th_pk`。
3. **截断须自查。** 计算窗口外的近场被截掉（等价于乘方窗 → 远场多一次 sinc 卷积）。
   外推距离按最外两层各算：`depth = 20/γ`（上限 50 μm），本结构衬底侧 0.9 μm、
   覆盖层侧 3.2 / 4.4 / 12.2 μm（TE0/1/2）。当前截断处场强 ≈ e⁻²⁰，可忽略；
   存疑时把 `opts.tail_dec` 由 20 改 40 重跑，FWHM 不变即证明无影响。

细节与算例见 `Mode_L1_V1.0/Model_Self_L1_7L_EBL.m` 中 `far_field` 的函数头说明。

### 3.3 已知的接口摩擦点

- **`build_layers.m:60` 断言 `imag(n) >= 0`** ⇒ 层折射率不能有负虚部。阶段 4 若走"负虚部表示增益"会被直接拒绝；
  计划的"`Γ·g` 显式求和"路线不冲突（见 §1.3）。

  → **需要换成散射矩阵法（S 矩阵）**，这是阶段 2 开工清单的第 ② 项。
