## 2. 第一遍（约 40 min）：概念地图 —— 不碰代码

### 读三处

**① `../GaN_LD_分阶段学习与建模路线.md:76` —— 阶段 1 的核心物理：横向驻波条件**

```
横向往返相位   2κd − 2φ₁ − 2φ₂ = 2πm
```

每满足一次，就多一个模式。

> ⚠ 同文件 `:78` 有一条**方向性警告**，必须背下来：此处驻波是**横向（y）**的，
> **不是**纵向（z）腔模驻波。纵向驻波周期 λ/2n ≈ 92 nm，被载流子扩散（L_d ≈ 0.5–2 μm）
> 抹平，在本课题里是**死通道**。阶段 1 的腔长 L 根本不出现在方程里。

**这条为什么必须背**：导师那句"模式竞争"的分歧正落在这里——
纵模/模簇竞争 vs 侧向模竞争，验收量完全不同（`../GaN_LD_研究方向与文献清单.md:495`，阻塞级第 1 条）。

**② `分阶段路线.md:223`（概念 #1：β、n_eff、本征方程在解什么）+ `:225`（概念 #3：Γ 的两种定义，为什么文献数值不可比）**

**③ `DS_Deve/README.md:83-99` —— 单位与符号约定（唯一出处）**

| 量 | 约定 |
|---|---|
| 长度（层厚 d、λ、坐标 y） | **μm** |
| 真空波数 | k₀ = 2π/λ [μm⁻¹] |
| 传播常数 | β = k₀·n_eff [μm⁻¹]，转 cm⁻¹ **乘 10⁴** |
| 吸收系数 | α [cm⁻¹] = 2·k₀·Im(n_eff)·**10⁴** |
| **符号** | 时间因子 exp(−iωt)、沿 +z 取 exp(+iβz) ⇒ **Im(n_eff) > 0 = 损耗，< 0 = 净增益** |

同一套约定也写在 `V1.0/README.md:104-112`。**两处必须一致**——不一致就是隐患。
阶段 1 全部取 Im(n_eff) = 0，这条约定现在不起作用；它的价值在阶段 2 兑现
（若符号反了，"增益算成损耗"会让**所有数值检查照样通过**）。

### 2.1 三个你要能自己算出来的量（30 秒把手）

| 量 | 自己套的式子 | 把手 |
|---|---|---|
| 吸收系数换 cm⁻¹ | α = 2·k₀·Im(n_eff)·10⁴ | `DS_Deve/README.md:91` |
| 截止条件 | V_c,m = arctan(√a) + mπ，其中 a = (n_high² − n_low²)/(n_core² − n_high²) | `DS_Deve/README.md:143-147`（实测偏差 1e-12） |
