## 2. 模型能取到什么数据

### 2.1 返回结构体 `modes(k)`（按 n_eff 降序，`modes(1)` 是基模）

| 字段 | 含义 |
|---|---|
| `n_eff` | 有效折射率（本征值） |
| `beta` | 传播常数 = k₀·n_eff [μm⁻¹] |
| `order` | 模序，0 = 基模 |
| `y` | 模场横坐标 [μm] |
| `E` | 归一化后的模场 φ(y)（TE 为 E_y，TM 为 H_y） |
| `n_y` | 与 y 对应的折射率 |
| `Gamma` | **限制因子 Γ** |
| `norm_val` | 归一化积分值，应恒为 1（自检用） |
| `P_layer` | **各层功率占比**（长度 = 层数，总和 = 1） |
| `yb` | 各层的 [y_lo, y_hi] |
| `ff` | **快轴远场**，子字段见下 |

**`modes(k).ff` 的子字段**：`theta`（角轴 [rad]，±π/2）、`I`（角分布 \|Φ(θ)\|²，峰值归一）、
`fwhm`（半高全宽 [rad]）、`th_pk`（峰值角 [rad]）。

> ⚠ 多瓣模的 `fwhm` 要连 `th_pk` 一起读：瓣间凹陷**浅于半高**时它横跨数瓣，
> **深于半高**时只覆盖一瓣。详见《开发坑记录》C4。

### 2.2 层结构定义

改层结构只需改 `stack_7layer()` / `stack_9layer_mqw()` 里的**四个等长数组**：`d`（厚度）、`n`（折射率）、`tag`（层名）、`is_active`（是否属有源区）。
**首尾必须是 `Inf`**（半无限）。加层 = 在四个数组的同一位置各插一个元素。

- 改**层厚/折射率/层数/有源区** → 只改这四个数组
- 改**波长/偏振/求几阶模** → §1 的 `lambda` / `pol` / `n_modes`
- 改**采样密度/容差** → §1 的 `opts`

## 4. 表（MATLAB 图窗内的可交互表格）

运行模型时会弹出 `GaN LD - data tables` 窗口，含两张可**选中复制、点表头排序**的表：

| 表 | 行 | 列 |
|---|---|---|
| **表一：各模式** | 每个模式 | 模序 / n_eff / β / Γ / FWHM / 峰值角 / norm 自检 |
| **表二：各层** | 每层 | 层号 / tag / d / n / **各模式的 P_layer(%)** |

**版式**：列宽按窗口宽度**等分铺满**（字号 16 pt）；窗口可横向拉伸，列宽自动重排；高度按行数贴合。

> ⚠ `uitable` 是 UI 控件，`exportgraphics` **导不出**它 —— `'save'` 模式只导图。
> 要取数可在窗口里选中复制，或直接用返回的 `modes` 结构体。
>
> ⚠ **改表格版式前先读《开发坑记录》E4**：`ColumnWidth` 默认 `'auto'`，不会铺满控件 ——
> 只放大 `Position` 会得到"大框 + 小表格 + 大片空白"；传统 figure 的 uitable **没有
> `RowHeight` 属性**，行高不可控，所以控件高度按行数贴合（重排函数见 `relayout_tables`）。

## 5. 结果摘要（7 层结构，λ = 450 nm）

| 模 | n_eff | Γ | 快轴 FWHM | 峰值角 |
|---|---|---|---|---|
| **TE0** | 2.41712846 | **0.026775** | 23.95° | 0.00° |
| TE1 | 2.39631649 | 0.002285 | 34.83° | −8.91° |
| TE2 | 2.37688371 | 0.002986 | 15.70° | −18.09° |

**9 层 MQW 结构**（阱-垒-阱）：TE0 n_eff = 2.41619520、**Γ = 0.017041**（阱变薄，Γ 下降）。

**各层功率占比（7 层 TE0）**：衬底 0.0001% / n-clad 33.0619 / n-wave 34.9696 / **QW 2.6775** / p-wave 17.8844 / EBL 2.5646 / p-clad 8.8419。

**三条物理结论**：

1. **TE0 是唯一被真正关在芯区的模**（芯区 55.5%），且光明显偏向 n 侧（n 侧 68.0% vs p 侧 29.3%）——
   原因是 EBL 的折射率凹陷把光往 n 侧推。
2. **TE1 / TE2 的功率绝大部分落在 n-clad**（94.0% / 83.0%），因为 n_eff < n_clad = 2.404，
   光在 n-clad 里不再是倏逝衰减而是振荡传播。它们几乎不碰量子阱（Γ 只有 0.002），
   **属于应当被抑制的模式**。
3. QW 只有 9 nm（占结构总厚 0.63%），却拿到 TE0 的 2.68% 功率 —— 场强密度是平均值的 4.2 倍。

## 6. 验证结论

| 项 | 方式 | 结果 |
|---|---|---|
| **A1–A7 验收** | `cd DS_Deve; startup; run_stage1` | **47 PASS / 0 FAIL** |
| **V1.0 层结构独立核查** | `crosscheck_v1_layers` | 35 PASS / **2 FAIL** |

**关键数字**：A1 = 1.09e-08（判据 < 1e-6）、A2 = 3.99e-14、A3 ≈ 1e-12、A5 = 4.44e-16、
A0 符号核对 max\|行列式\|/κ³ = 4.464e-14。

**两个 FAIL 的说明**：都在 P8，都是 `solver='fdm'` + `pol='TM'` —— fdm 的 TM 分支失效（静默返回 TE）。
**当前阶段影响为 0**（主线 TE、生产路径 tmm，且单文件模型不含 fdm）。
同一节的 `analytic vs tmm = 4.01e-14` 与 `TM ≠ TE` 两条均 PASS，
证明 **analytic3 与 tmm 的 TM 都是对的**，坏的只是 fdm 这把尺子。
