# 阶段 1：非对称多层平板波导本征方程

**GaN 基高功率蓝光 LD 光学结构设计 —— 第一阶段**
**完成日期**：2026-09-20 ｜ **工具**：MATLAB R2023b

---

## 1. 本阶段做了什么

建立了一个**非对称多层平板波导的 TE/TM 本征模求解器**，输出：

- 各阶模的**有效折射率 n_eff**（本阶段为实数，接口已按复数实现）
- 各阶模的**模场剖面 φ(y)**
- 各阶模的**限制因子 Γ**，以及**各层的功率占比**
- 各阶模的**截止条件**（解析式与数值双路）

求解器刻意做成**三条相互独立的路径**，用其中两条给第三条当标尺——理由见 §3。

## 3. 三条求解路径，以及为什么需要三条

| 路径 | 方法 | 层数限制 | 独立性来源 |
|---|---|---|---|
| 1 `analytic3` | 解超越方程 κd = arctan(γ_s/κ)+arctan(γ_c/κ)+mπ，二分 | 仅三层 | 公式形式已用**符号运算**独立推导核对（t00） |
| 2 `tmm` | 2×2 传输矩阵连乘，求色散函数零点 | 任意 | 数学路径与路径1 完全不同 |
| 3 `fdm` | 把 Helmholtz 方程离散成稀疏矩阵本征值问题，`eigs` | 任意 | **连色散方程这个中间产物都不要** |

**为什么不能只留两条**：路径 1 与路径 2 虽然数学路径不同，但都由同一套"分层 + 界面连续 → 色散方程"的推导而来。若推导本身写错（比如 TM 的界面条件写成 TE 的、或衰减解取了增长分支），**两条会一起错**，A1/A2 双双通过而结果是错的。

这正是交接报告里 A1 的隐患：**"解析解"本身也是数值求根得来的，不能自证**。所以本阶段做了两件事补这个洞：

1. **t00** 用 Symbolic Math Toolbox 从 Maxwell 方程 + 界面连续条件重新推导色散方程，与代码里手写的逐项比对（结果：差为 0）；
2. **路径 3** 绕过色散方程，直接从偏微分方程离散。

生产计算用 `tmm`（任意层数）；`analytic3` 与 `fdm` 是它的两把标尺。

## 4. 核心约定（后续 5 个阶段全部复用，不得另立门户）

### 4.1 单位

唯一定义处是 `startup.m` 的头注释：

| 量 | 单位 |
|---|---|
| 长度（层厚 d、波长 λ、坐标 y） | **μm** |
| 折射率 | 无量纲，n = n′ + i·n″ |
| 真空波数 | k₀ = 2π/λ [μm⁻¹] |
| 传播常数 | β = k₀·n_eff [μm⁻¹]，转 cm⁻¹ 乘 10⁴ |
| 吸收系数 | α [cm⁻¹] = 2·k₀·Im(n_eff)·10⁴ |

### 4.2 符号与时间约定

时间因子取 exp(−iωt)，沿 +z 传播取 exp(+iβz)，于是

α = 2·Im(β) = 2·k₀·Im(n_eff)

**结论：Im(n_eff) > 0 表示损耗，Im(n_eff) < 0 表示净增益。**
阶段 1 全部取 Im(n_eff) = 0，但约定先行写死——否则阶段 2 引入复折射率后，"增益算成损耗"这类错误会静默通过全部数值检查。

### 4.3 Γ 的定义（写在 `confinement_factor.m` 首行）

```
        Γ ≡  ∫_{有源区} w(y) dy  /  ∫_{-∞}^{+∞} w(y) dy

        TE :  w(y) = |E_y(y)|²
        TM :  w(y) = |H_y(y)|² / n(y)²
```

物理含义：**有源区内的净功率占总功率的比例**，无量纲、0 ≤ Γ ≤ 1。

**为什么两处都必须钉死**（文献里 Γ 不可比的根源）：

1. **分子范围**：单阱 / 全部阱层并集 / MQW 区（含势垒）——阱垒厚度相当时这三者能差 2–3 倍。本项目取 **全部 `is_active` 层的并集（不含势垒）**。
2. **分母范围**：无穷积分 vs 截断到外延结构。对漏模只有无穷积分自洽。本项目取无穷积分。

配套口径：`Γ(全部阱) × g(单阱材料增益)`。若某处改用 MQW 区平均材料增益，必须另算一个 Γ_MQW，**两者不可混用**。

### 4.4 层序方向

`L(1)` 在底（衬底侧），`L(end)` 在顶（覆盖层侧），y 随层号递增。**首尾两层厚度必须为 `Inf`**（半无限），`build_layers.m` 会直接报错而不是静默容忍——截断最外层会解出物理上不存在的假离散模。

⚠ **不预设"光偏向哪一侧"**。偏向由两侧包层实际折射率与厚度决定，代码内部按"较高的那个包层"统一处理。t05 用一对镜像结构专门验证了这一点。

**A3 的一个必要精确化**：非对称结构下"与通用色散曲线吻合"这句话本身没有判定标准。教科书那条单一曲线是 a = 0（对称）的特例。本项目引入不对称度

a = (n_high² − n_low²) / (n_core² − n_high²)

以 a 为参数画曲线族，再核对截止条件 V_c,m = arctan(√a) + mπ，A3 才可判定，也才真正回避了绝对折射率取值的不确定性。

## 6. 典型 GaN LD 层序的结果（`layers_gan_ld_typical.m`）

λ = 450 nm，TE 模。⚠ 折射率是**典型量级**（由文献折射率对比外推），**不适用于任何定量对标**；真实外延结构应尽早向企业索取并整体替换本文件。

| 模 | n_eff | Γ | 说明 |
|---|---|---|---|
| TE0 | 2.417849 | **0.0273** | 束缚在 InGaN 波导 + QW 区（y ≈ 1.20–1.41 μm） |
| TE1 | 2.396380 | 0.0022 | n_eff < n_clad，有效芯区扩到整个 n-AlGaN 层 |
| TE2 | 2.376658 | 0.0034 | 有效芯区进一步展宽，双峰 |

**各层功率占比（TE0）**：n-clad 31.9%、n-wave 35.1%、QW 2.7%、p-wave 18.5%、p-clad 11.7%、衬底 0.00006%、覆盖层 0.0018%。

**这张表本身就是一个结论**：光有 30.2% 落在 p 侧、67.0% 落在 n 侧——**光场明显偏向 n 侧**，因为 n 侧是 AlGaN（n = 2.404）而 p 侧顶上是空气（n = 1.0）。这正是 A6 说的"不预设方向、按真实层序判断"。

⚠ 本层序把覆盖层简化成了空气。真实的 p 侧是 p-GaN 接触层 + Pd 电极，Pd 在 450 nm 的吸收系数约 8.9×10⁵ cm⁻¹，会构成一条独立的损耗通道——**这是阶段 2 要处理的第一件事**。

## 8. 已知限制（不要当成结论使用）

1. **折射率是典型量级**，末位不可靠。阶段 1 的验证刻意设计成不依赖绝对值（V 数验证），正是为了回避这一点。
2. **覆盖层用空气代替金属电极**，低估损耗。
3. **QW 用单层等效（9 nm, In0.15GaN）**，不是真实 MQW。阶段 2 起若要算 Γ 与阱垒的精细重叠，必须展开成真实阱/垒层序。
4. **FDM 路径的截断**：Dirichlet 边界会把辐射模离散成假模，已用"n_eff 必须大于两侧包层折射率"剔除；接近截止的高阶模可能被误剔（t01 会告警）。
5. **Γ 的绝对值不宜与文献直接比较**——口径不同（见 §4.3）。
6. **复根搜索的可靠性尚未系统验证**：阶段 1 只做了冒烟测试。阶段 2 必须补后验检查（把根代回 \|f\| 与邻域比较，剔除鞍点伪根）。

## 9. 开发中踩过的坑（记录备查）

这几处错误都不会报错，只会安静地给出错的结果——所以特意留在注释里：

1. **`find_roots_complex` 按升序截断** ⇒ 保留了"最靠近截止的一批高阶模"，把基模挤掉。**波导问题必须保留最大的 n_eff。** 现象：analytic 与 TMM 的模数一致但 n_eff 系统性错位。
2. **`eigs` 的选项名**：合法的最大实部选项是 `'lr'`，不是 `'largestreal'`。
3. **`eigs` 在 'lr' 模式下不收敛**：矩阵尺度是 1/h² ≈ 7×10⁵，而目标本征值只有 ~484，谱顶极度密集。改用 **shift-invert**（给一个略高于谱顶的位移 σ）。同时注意：**用数值 σ 时 `issym` 会被忽略并发出警告**，不要设它，否则真警告会被淹没。
4. **截止判据不能用 `f(n_high + δ)` 的符号**：这样会把截止点系统性抬高 arctan(γ(δ)/κ) ≈ k0·√(2n·δ)/κ，δ = 1e-9 时偏差约 **2×10⁻⁴**。这个量级足以让 A3/A4 卡在 1e-4 附近过不去，而它完全是判据引入的假偏差。改用**解析极限值** g_m = κ_max·d − arctan(γ_low/κ_max) − mπ。修正后偏差降到 1e-12/1e-14。
5. **绘图时 `patch` 给了固定高度 1e3**，把纵轴顶到 1000，三条曲线被压成贴地直线。用 `xregion`（自动铺满纵轴、不改 ylim）。
6. **Γ 的两种定义不可混用**（有源区功率占比 vs MQW 区平均场强），也**不能只钉死一处**——分子范围和分母范围是两个独立的坑。

## 10. 阶段 1 的边界声明

- 本阶段只解**截面问题**（y–z 中的 y 方向）。腔面损耗 α_m、腔长 L、端面反射率 R₁R₂ **一律不出现**，它们归阶段 6。
- 全程**稳态**，不涉及横-纵模竞争（60–80 MHz 的动力学现象）。
- 本阶段的 n_eff 与 Γ **不含**增益、载流子、温度的任何反馈——那些分别属于阶段 4、5。
- **"泄漏"在本阶段完全没有出现**：光学泄漏归阶段 2，载流子泄漏归阶段 5，两者是不同的量。
